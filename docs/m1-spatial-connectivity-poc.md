# 空间连接技术原型

## 范围与选型

现有 M1-04 数据包探针、M1-06 实机链路可供未来验证适配，但仓库没有可复用的连接图和路由器，现有构建也没有图依赖。本轮只验证数据结构和算法，不调用维度注册表、传送、坐标缩放、区块加载或游戏事件。源码位于 `src/testFixtures`，不会进入生产 JAR；沿用现有 JUnit 测试入口。

| 方案 | 评估 |
| --- | --- |
| JDK 邻接表 + [ArrayDeque](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/ArrayDeque.html) 广度优先搜索 | 采用。只使用 JDK 稳定 API，无额外许可证、依赖信任或 NeoForge 打包成本。无权有向图查询走访至多一次每个顶点和边，时间复杂度 O(V + E)，只在建图时排序相邻边。 |
| [JGraphT](https://jgrapht.org/) | 可复用通用图及搜索算法、维护和许可均有公开资料（LGPL 2.1 / EPL 2.0 双许可），但当前没有权重、约束搜索或多算法需求；引入要额外复核依赖、许可义务与目标 Mod 加载配置，不值得为本原型增加集成成本，未复制其实现。 |
| 直接使用 Minecraft 维度或 NeoForge 事件实现路由 | 仅留作后续适配方向。引擎 API 与版本和加载时序绑定；现阶段无法据此推断真实地图、事件规则或授权关系。 |

## 原型可以验证什么

- 输入只包含独立节点标识与有向连边（边 ID、起点、终点）；拒绝空标识、重复节点或边 ID、引用不存在节点的边。测试夹具仅用 `n0`、`e0` 一类合成 ID。
- 构建后图和返回路径不可变。不对边作隐式反向补全。同起终点返回有效空路径，不可达返回空结果，未知节点拒绝查询。
- 为测试确定性，按边数找最近路径，同长度时用邻接表的目标 ID、边 ID 顺序决定遍历顺序；这不是正式路线、通行优先级或设计规则。用已访问集合阻止循环。
- 不定义正式布局、节点含义、地图、触发条件、玩家状态、动态道路、数据格式或世界观。接入真实维度前应重新评审规则、数据版本、可达性约束和性能预算；不能把算法单测当作实机通行证明。

验证：目标仓库可在 Java 25 环境执行 `./gradlew test --tests '*SpatialGraphTest'`；完整 CI 仍按仓库现有流程执行。
