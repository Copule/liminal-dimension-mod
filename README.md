# 《未完全死亡》

This is the Minecraft Java Edition mod project 《未完全死亡》. The current phase
covers the project foundation, underlying technology and necessary test
infrastructure. The in-game display name is `未完全死亡` and the internal
Mod ID is `liminal_dimension`.

The M0 engineering bootstrap is complete. [PR #1](https://github.com/Copule/liminal-dimension-mod/pull/1)
was merged into `main`. The packaged mod passed the [M0-07 single-player Demo
acceptance](docs/architecture.md#m0-07-single-player-world-acceptance-2026-11-18).
The current development scope remains the project foundation, underlying
technology and necessary test infrastructure.

See the [roadmap](docs/roadmap.md) for milestone status and the
[architecture notes](docs/architecture.md) for build and verification results.

If you are working on the repository, start with the [agent guide](AGENTS.md)
and open only the relevant section of the [documentation map](docs/index.md).
